# biodata-schema

[![License](https://img.shields.io/badge/license-MIT-brightgreen)](LICENSE)
![Code Style](https://img.shields.io/badge/code%20style-ruff-D7FF64)
[![Documentation Status](https://readthedocs.org/projects/biodata-schema/badge/?version=latest)](https://biodata-schema.readthedocs.io/en/latest/?badge=latest)

A library that defines the biodata schema and validates JSON files. This schema is intended to support biological data including physiology, behavior, anatomy, imaging, transcriptomics, and more. 

## Installation

```python
pip install biodata-schema
```
